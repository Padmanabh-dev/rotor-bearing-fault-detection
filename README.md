# Rotor Bearing Fault Detection Using Machine Learning

## Overview

This project focuses on the detection and classification of rotor-bearing faults, specifically shaft misalignment and inner race bearing defects, using vibration signal analysis and machine learning techniques.

The study investigates the vibration characteristics of a rotor-bearing system under different operating conditions and defect sizes. Experimental vibration data were collected using accelerometers and analyzed using machine learning algorithms.

## Objectives

* Detect shaft misalignment in rotor-bearing systems.
* Identify inner race bearing defects.
* Analyze vibration signatures under different operating conditions.
* Compare machine learning algorithms for fault classification.

## Machine Learning Algorithms

The following algorithms were investigated:

* Decision Tree
* Random Forest
* Support Vector Machine (SVM)

## Experimental Setup

The experimental setup consists of:

* Rotor shaft assembly
* Deep groove ball bearings (6206)
* Electric motor with speed control
* Accelerometer sensors
* FFT Analyzer

Operating Speeds:

* 720 RPM
* 1000 RPM
* 1440 RPM
* 2160 RPM

Misalignment Levels:

* 0 mm
* 0.25 mm
* 0.5 mm
* 0.75 mm
* 1 mm

Defect Sizes:

* 3.2 × 5.1 mm
* 3.2 × 8.2 mm
* 5.1 mm
* 8 mm
